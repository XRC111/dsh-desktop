# DSH Desktop 用户手册

面向最终用户。你不需要安装 Node.js、npm 或任何命令行工具。

---

## 一、安装

1. 双击 `DSH-Desktop-Setup-1.0.1.exe`
2. 阅读并接受许可协议
3. 选择安装位置（默认 `%LOCALAPPDATA%\Programs\DSH Desktop`，无需管理员权限）
4. 选择是否创建桌面快捷方式（默认创建）
5. 完成后可选择立即启动

> **Windows 提示"已保护你的电脑"？**
> 这是 SmartScreen 对未签名程序的通用提示。点击「更多信息」→「仍要运行」即可。
> 企业环境可通过代码签名彻底消除该提示。

## 二、首次启动

启动后你会先看到一个加载页（显示"正在启动本地服务…"），随后自动进入 DeepSeek Harness 界面。

**首次启动会慢一些**，加载页会持续显示已等待时间：

Harness 运行时会随安装过程一起写入，因此首次启动只需要初始化本地环境
（`%APPDATA%\DSH-Desktop\dsh-home`，一次性建立配置与插件目录）。

在普通固态硬盘上通常需要十几秒到 1 分钟；如果磁盘写入较慢或杀毒软件实时扫描较严格，
可能需要更久。**请不要关闭窗口**，加载页的计时器会一直走动。

之后启动通常在数秒内完成。

进入界面后，按 Harness 自身的方式使用即可（配置模型 API Key、创建会话等）。
本应用不改变 Harness 的任何行为。

### 自定义数据位置（可选）

如需把数据目录放到别处（例如更快的磁盘），可在启动前设置环境变量：

```powershell
set DSH_DESKTOP_HOME=D:\dsh-data
```

设置后 Harness 的配置、会话与插件都会存到该目录。

## 三、窗口与托盘

| 操作 | 结果 |
| --- | --- |
| 点击窗口关闭按钮 | **最小化到托盘**，Harness 服务仍在后台运行，界面状态保留 |
| 点击托盘图标 | 显示 / 隐藏主窗口（毫秒级恢复） |
| 托盘右键 → 显示主窗口 | 唤出窗口 |
| 托盘右键 → 重启 Harness 服务 | 重启本地服务（界面回到加载页） |
| 托盘右键 → 打开日志目录 | 打开日志文件夹，便于排查问题 |
| 托盘右键 → 打开数据目录 | 打开用户数据文件夹 |
| 托盘右键 → 完全退出 | 停止 Harness 服务并退出，托盘图标消失 |

> 想彻底关闭：请使用托盘菜单的「完全退出」，而不是关闭窗口。

## 四、数据与日志位置

| 内容 | 路径 |
| --- | --- |
| 用户数据根目录 | `%APPDATA%\DSH-Desktop` |
| Harness 配置 / 会话 / 插件 | `%APPDATA%\DSH-Desktop\dsh-home` |
| 外壳日志 | `%APPDATA%\DSH-Desktop\logs\app.log` |
| Harness 服务日志（stdout/stderr） | `%APPDATA%\DSH-Desktop\logs\dsh-web.log` |
| 窗口尺寸偏好 | `%APPDATA%\DSH-Desktop\window-state.json` |

日志单文件超过 10 MB 会自动轮转（保留最近 3 个历史文件），无需手动清理。

## 五、常见问题

### 1. 端口 3080 被占用

应用会自动改用系统分配的空闲端口，加载页与日志会提示这一情况。
**通常无需任何操作**，Harness 界面照常可用。

若想固定使用 3080，请先释放占用该端口的程序：

```powershell
netstat -ano | findstr :3080      # 找到 PID
taskkill /PID <PID> /F
```

### 2. 启动失败 / 一直停在加载页

1. 点击加载页上的「重试」
2. 仍失败时点击「打开日志目录」，查看 `dsh-web.log` 末尾的报错
3. 点击「复制诊断信息」，可把环境与状态信息粘贴给技术支持

常见原因：

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 提示运行时校验未通过 | 安装不完整 | 重新安装 |
| 服务端口无法连接 | 安全软件拦截本地监听 | 将 `DSH Desktop.exe` 加入白名单 |
| 启动超时 | 首次初始化较慢或磁盘繁忙 | 稍后重试 |
| 进程瞬间退出 | 依赖损坏或被拦截 | 重装；必要时在安全软件中放行 |

### 3. 界面空白 / 需要刷新

托盘菜单 → 重启 Harness 服务。若仍空白，完全退出后重新启动应用。

### 4. 杀毒软件报警

应用内含以 Node 模式运行的本地服务进程，部分杀软会提示。
将 `DSH Desktop.exe` 及其安装目录加入信任列表即可。

## 六、卸载

1. 先通过托盘菜单「完全退出」
2. 设置 → 应用 → 已安装的应用 → DSH Desktop → 卸载
   （或使用开始菜单中的卸载入口）

卸载过程会：

- 先终止 `DSH Desktop.exe` 及其全部子进程
- 删除安装目录与快捷方式
- **询问是否删除用户数据**（`%APPDATA%\DSH-Desktop`）；选择「否」则保留，便于重装后继续使用

静默卸载：`"Uninstall DSH Desktop.exe" /S`

## 七、静默安装（批量部署）

```powershell
.\DSH-Desktop-Setup-1.0.1.exe /S
```

按用户静默安装，安装完成后不自动启动。各用户首次登录时从开始菜单启动即可。
